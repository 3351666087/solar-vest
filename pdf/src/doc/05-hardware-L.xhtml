最易出错处：P-MOS 的体二极管方向 Q3/Q4 若方向接反，即使栅极关断，体二极管仍会让两块电池经二极管并联。 建议直接采用带反向阻断的理想二极管 IC（如 LM66100）规避，比分立 FET 背靠背可靠得多。
原理图评审时逐个画出体二极管方向确认；装配后用万用表验证： Q3 关断时 BAT_A+ 与 LOAD_BUS 之间双向都不通（单向导通即为方向错误，返工）。
防拉脱：一根线缆穿过身体 跌倒、更衣都会拉扯它。必须用磁吸或易断连接器（> 约 20 N 时先断连接器而非扯动电极）， 线缆留松弛量并用走线夹固定；断连后超容维持供电 → MCU 记录事件 → 有序关断。
