SECTION 05 · SOFTWARE

软件层　多源对齐、存储与可复现

三条独立无线链路、两种时间基准、一个必须能在三个月后复现的结论。 这一层的工程量被低估的程度，通常和它决定实验成败的程度成正比。

5.1　技术栈选型

环节选型理由 / 约束
BLE 采集bleak (asyncio)跨平台；需实现背压与自动重连
BT 经典采集pyserialBITalino 若为 BT 版；重连慢，影响功率循环策略
原始信号Parquet (列存)1000 Hz × 多通道 × 小时级；关系库不划算
遥测时序TimescaleDB超表 + 连续聚合；EAR 按窗口积分
心电处理NeuroKit2R 峰检测与 HRV；黄金用例回归
看板Grafana能量 / 温度 / 状态机实时视图
实验记录YAML manifest + Git与数据同仓库提交，不可事后补写
CIpytest + schema含「manifest 的 fw SHA 必须真实存在」校验
一条看似吹毛求疵、但最有效的实验纪律 CI 校验每份 manifest 里的 firmware_git_sha 在仓库中真实存在。 它会强制你先提交固件、再做实验，而不是「改完随手跑一下，回头忘了改过什么」。
