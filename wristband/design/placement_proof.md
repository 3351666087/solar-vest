# SolarBand V3-F: how each rotation-sensitive placement is proven (BASELINE 16; v2 review R-07, R-19)

Generated by `tools/placement_proof.py` from the footprints the board uses (`lib/easyeda_rev.pretty`) and the netlists of all variants. 'Copper fits at 180 deg' is computed: the pad set, turned about the centre of its bounding box, lands on itself within 0.03 mm; 'within 0.10 mm' marks a near-symmetric land (one pad differs by <= 0.10 mm), which is treated as 2F because the geometry is too close to decide. 'Same nets after 180 deg' is computed from the netlist. R, C and L are non-polar and not listed. Nothing here was run on hardware: G10 items are requirements for the test jig.

Classes (ARCHITECTURE 10.3): **1F** pad geometry decides (cplgate G4); **2F / 4F** the copper fits turned, identity evidence (pin map + electrical test) is mandatory; **P** polar two-terminal part (human-reviewed pin map + electrical test); **N** a turned part connects the same nets; **M** mechanically polar, electrically neutral.

Baseline v3f: 1F: 26, 2F: 14, 4F: 2, M: 6, N: 9, P: 5.
