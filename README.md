# Solar Vest · 太阳能自供电可穿戴心电背心

A self-powered, solar-harvesting wearable for ECG research. A rigid 6 V / 6 W panel rides on a vest. It charges a 1S Li-Po through an MPPT charger board of our own design. The battery powers three BITalino biosignal units that stream ECG/PPG over Bluetooth, while six INA226 monitors log every energy path.

一件为心电研究做的太阳能自供电可穿戴设备：
- 背心上装一块 6 V / 6 W 硬质太阳能板，通过自研 MPPT 充电板给单节锂电充电；
- 锂电给三台 BITalino 生理信号采集单元供电，心电和 PPG 经蓝牙传到手机；
- 6 路 INA226 记录每一条能量路径。

**Status (2026-10)**:
- Both PCBs have been manufactured and assembled by JLCPCB.
- All parts are in hand and all enclosures are printed.
- The vest itself is not sewn yet. At the supervising vice dean's request the next step is a bench bring-up of the whole electronics, before the vest is built.

**进度（2026-10）**：
- 两块 PCB 已由嘉立创生产贴片；
- 元件已全部到货，外壳已打印完成；
- 背心还没缝制。按副院长要求，下一步先在桌面上把整套电路联调通过，再做背心。

## System at a glance · 系统一览

| Block | What it is |
|---|---|
| Panel | 6 V 6 W rigid panel, 12 cells (2 × 6), on six printed shoes with an 18–53 mm air gap |
| **PMB-H** (back pod) | CN3791 MPPT charger (set point ≈ 6.3 V), night back-feed cut-off, 6 × INA226 (panel high/indoor range, battery, load, 2 reference cells), XIAO nRF52840 Sense logger |
| **LIB** (chest pod) | Hold-up board: feeds BITalino Core B through an LM66100 ideal diode; 2 × 10 F supercaps take over if the supply drops |
| BITalino A / B / C | A: HeartBIT (Core BT) + ear-lobe PPG, B: Core BLE (solar-powered DUT), C: Board Kit BLE on its own battery (control) |
| Reference cells | REF1 in the panel plane, REF2 level on the shoulder (light meters) |
| Harness | 20 wires, specified pin-to-pin with routed lengths |

## Quick start · 快速上手

- **See the design**: open `制造文件/SolarVest_Explorer/index.html` in Chrome, Edge or Safari. Press `P` for the guided tour, `X` for X-ray and `E` to explode.
- **Print the parts**: `制造文件/3D打印/` (use the `.3mf` files; read `打印清单_README.txt` first).
- **Order the boards**: the files in `制造文件/PCB/<board>/` named `*_gerber_JLC.zip`, `*_BOM_嘉立创.xlsx` and `*_坐标_嘉立创_v3.xlsx`.

## Rebuilding · 重新生成

Everything here is generated by code, with no GUI CAD:

| What | How |
|---|---|
| Explorer | `cd 制造文件/源码/SolarVest_Explorer_src && npm install && npm run build` (three 0.160, three-mesh-bvh 0.8, esbuild). The output lands in `dist/`. |
| Enclosures | Python 3.12 + `build123d trimesh manifold3d scipy shapely`. Run `SV_PLACEMENT=制造文件/背心/placement.json SV_META_IN=制造文件/3D打印/parts_meta.json python 制造文件/源码/enclosures.py`. The panel shoes additionally need the body model, which is not included. |
| Fit check | `python 制造文件/源码/check_fit.py <parts dir> 制造文件` reports interference and free travel of every board and battery. |
| PCBs | KiCad 10 + SKiDL: `制造文件/源码/pmbh.py`, `libb.py`, then `place_*.py`, `fab.py` (Gerbers, BOM, CPL), `jlc_rotcheck.py` (pad-matched placement rotations). |
| Simulation | ngspice through KiCad's bundled libngspice: `制造文件/源码/仿真/`. |

Some scripts were written for the original workstation and expect tool locations (KiCad app path, scratch directories) that you may need to adapt.
