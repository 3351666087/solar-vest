## 0. Conclusions

| Question | Conclusion |
|---|---|
| Which 3D models can be found online directly? | **All chips and connectors can be found**, e.g. CN3791, INA226, LM66100, LM74700, AO3401, YJL3404A, SS34, JST-PH/XH. **The XIAO nRF52840 Sense has an official Seeed STEP** ✅. The AEM10941 chip has manufacturer CAD ✅ |
| Which must be built ourselves? | **None of the "module boards" or "complete items" have reliable official models**: panel, battery, supercapacitors, CN3791 module, INA226 module, EVK10941, the BITalino and its enclosure, electrodes, plus the backplate, enclosures and vest. | Can the PCB be developed on a command-line platform? | **Yes.** Recommended: **KiCad 10 + code-described circuit + Freerouting autorouting + kicad-cli to output every file**. | Can we get 3D of the PCB? | **Yes, and automatically.** `kicad-cli pcb export step/glb` exports the board together with the 3D of every component on it; the component models come from the two categories above |

## 3. Which PCBs to make

Following the v3 split topology (ADR-007), there are 2 boards, plus 1 optional small board:

| Board | Location | Function | Complexity |
|---|---|---|---|
| **PMB-H** | Back | Panel input protection (fuse, TVS, diode) → CN3791 module; dual-battery switching; 4× INA226 (addresses 0x40 panel, 0x41 battery, 0x42 load, 0x44 reference cell); XIAO Sense; Q0 charge switch (on by default, to avoid a cold-start deadlock); NTC; J6 cable port | Moderate. **Rev A is built as a "module carrier board"**: CN3791, INA226 and XIAO all plug in as off-the-shelf modules, and the board itself only has connectors, MOSFETs and a few resistors and capacitors |
| **LIB** | Chest | Supercapacitor hold-up, load switch, sync-pulse injection into BITalino I1, ESD, JST-PH to the BITalino | Simple, about 25×20 mm |
| REF (optional) | Panel frame | Sense resistor and wiring for the reference cell | Minimal; can also be merged directly into the PMB-H |

All are 2-layer boards with low-speed signals; the finest parts are SOT-23 and 0603 passives, so **both the lab's PCB machine and JLCPCB can make them**.

## 5. Recommended pipeline

```
Circuit description (code, under Git)
   │  SKiDL (offline) or atopile (needs an account)
   ▼
Netlist + initial .kicad_pcb (all parts off-board, ratsnest only)
   │  Python placement script: mechanical constraints (board outline, holes, connector orientation) written as coordinates
   │  Switching loops (CN3791 periphery, shunt-resistor Kelvin traces) routed precisely by hand / script
   ▼
Freerouting autoroutes the remaining signal traces (DSN → SES)
   ▼
kicad-cli: if ERC / DRC fails, go back one step
   ▼
kicad-cli / KiBot outputs the full set:
   ├─ Gerber + drill → lab PCB machine or JLCPCB
   ├─ BOM + pick-and-place (if using contract assembly)
   ├─ PDF schematics, assembly drawings (for the supervisor and the lab)
   ├─ Rendered PNGs (which I use to self-check the layout)
   └─ STEP / GLB 3D (component models from Section 1)
   ▼
build123d final assembly: panel + backplate + PMB-H enclosure + cables + LIB enclosure + BITalino
   ▼
GLB → the existing 3D vest web page (replacing the current placeholder blocks)
```

**What I can and cannot do:**

- ✅ **I can**: write the circuit code; write placement and routing scripts; run autorouting and ERC/DRC; export all manufacturing files and 3D; produce renders for self-checking; do 3D modelling of all custom parts; do the final assembly and the web 3D.
- ❌ **You need to**: install KiCad; register an account (if choosing atopile); operate the lab's PCB machine; place and pay for the JLCPCB order; solder.
- ⚠ **Where quality will suffer**: the autorouter does not understand switch-mode power supplies. So the CN3791 power loop and the shunt-resistor Kelvin traces **must be routed precisely by script according to rules**, not left to Freerouting. After generating outputs I will attach renders, and you or the lab supervisor can take another look in the KiCad GUI.

## 6. Fabrication: lab machine vs. JLCPCB

| | Lab PCB machine | JLCPCB |
|---|---|---|
| Input | Depends on the machine type: a **CNC engraver** needs Gerber converted to G-code (pcb2gcode / FlatCAM, open source, not tested this time); **exposure / laser** needs a mirrored PDF or SVG (`kicad-cli pcb export pdf/svg` produces it directly) | Gerber zip archive, uploaded on the website |
| Capability | Unknown ❓. Without plated through-holes or solder mask, rules must be relaxed (trace width and clearance ≥ 0.3 mm, rivets for vias) | 2-layer / 4-layer, ENIG, solder mask all available; assembly service available |
| Lead time | Same day | 3–7 days |
| Recommendation | **Make the Rev A carrier board in the lab**: all large pads, quick to modify | **Send Rev B and the small LIB board to JLCPCB**: the small board needs higher precision, and since it is worn against the body it also needs solder mask and ENIG to resist sweat |

> **Please confirm: the brand and model of the lab's PCB machine.** A CNC engraver and an exposure/etching line need completely different design rules; I will set trace width, clearance and via method according to the machine's capability.
